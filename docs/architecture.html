Le socle de preuve

Deux primitives que toutes les couches réutilisent. C'est ça, la preuve.

ΓChaîne Γ

Journal append-only JSONL, chaque bloc chaîné par SHA-256 au précédent.

  • mode 600, verrou flock + verrou de thread
  • réécrire un bloc casse le chaînage
  • OCC : écriture refusée si la tête a bougé

✓Témoin indépendant

Un second sceau, hors de portée du système audité.

  • HMAC-SHA256 ou Ed25519 Python pur (RFC 8032)
  • recoupé avec cryptography (25 vecteurs)
  • détecte bloc par bloc : rompue, désaccord, bloc non témoigné
